# 📁 MultiConverter & Document Studio

A fast, lightweight, and 100% client-side document and media manipulation workstation. Everything runs offline in your web browser—no servers, no tracking, and complete privacy.

---

## ✨ Features

- 🗜️ **Target-Size Compressor:** Compress PDFs and images to a precise file size limit (KB or MB) using an automated bisection search algorithm.
- 📄 ➔ 🖼️ **PDF to Images:** Extract PDF pages into crisp JPG, PNG, or WEBP files with individual page downloads or 1-click batch ZIP export.
- 🖼️ ➔ 📄 **Images to PDF:** Combine single or multiple images into a clean PDF with custom page geometry (Fit to Image, A4 Portrait/Landscape) and margins.
- 🔄 **Image Format Switcher:** Quick offline conversion between JPG, PNG, and WEBP formats.
- 🔒 **Zero Server Overhead:** Built using HTML5 Canvas, PDF.js, jsPDF, and JSZip. Your files never leave your device.

## 🛠️ Built With

* [jsPDF](https://github.com/parallax/jsPDF) — Client-side PDF generation
* [JSZip](https://stuk.github.io/jszip/) — In-memory ZIP archive bundling
* **Vanilla HTML5 / Modern CSS / JavaScript** — Zero framework overhead
